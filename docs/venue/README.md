# Unity crowd demo

Open `ConcertVenue` in Unity **6000.0.23f1**. Keep the `shared` folder next to it. Open `Assets/Scenes/ConcertVenue.unity`, press **Play**, and switch to **Game**.

- **Normal flow:** visitors arrive at a steady rate.
- **Gradual rise:** the arrival rate increases over time.
- **Sudden surge:** arrivals start slowly, then jump.
- **Start run / Pause / Resume / Run again:** start, pause, continue or repeat the selected scenario.
- **Reset:** clear the run and keep the selected scenario.
- **Speed:** switch between 1×, 4× and 12×.

Picking a scenario clears the current run. **Reference** is the current density; **Sampled** is the last sensor reading, updated every five seconds. A dash means there is no sensor in that zone.
